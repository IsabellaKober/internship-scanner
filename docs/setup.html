📱 iPhone: dashboard as an app

  1. Open this site in Safari (it must be Safari, not Chrome or the Google app).
  2. Tap the Share button (square with an arrow ↑) at the bottom.
  3. Scroll down and tap Add to Home Screen, then Add.
  4. Open Internships from your home screen. It opens full-screen like an app.
  5. Enter your dashboard password and keep Remember on this device ticked.

The password is the DASHBOARD_PASSWORD secret you set on GitHub. If you change it there, re-enter it here after the next scan.

🔔 iPhone: push notifications (ntfy)

  1. Install ntfy from the App Store (free, by Philipp Heckel).
  2. Open it and tap + (top right).
  3. Type your topic name exactly, the same text as the NTFY_TOPIC secret, and leave the server as ntfy.sh.
  4. Tap Subscribe, then Allow when iOS asks about notifications.
  5. Missed the prompt? iPhone Settings → Notifications → ntfy → Allow Notifications.

You get one notification per strong new match (score ≥ 75), showing title, company and score. Tap it to open the offer. Keep the topic name secret: anyone who knows it can read the notifications.

🔄 Sync statuses & notes between iPhone and computer

Create one free GitHub token (no cost, no limit), then paste it on each device.

  1. On github.com: your photo → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Token name: internship-dashboard. Expiration: Custom → 1 year.
  3. Repository access: Only select repositories → internship-scanner-state.
  4. Permissions → Repository permissions → Contents: Read and write. Leave everything else as it is.
  5. Generate token and copy it. GitHub shows it only once, so keep it in Notes or your password manager.
  6. In the dashboard tap ⚙︎. Fill in State repository as <your-username>/internship-scanner-state and paste the token. Tap Test & sync now, then Save.
  7. Repeat step 6 on your other devices with the same token.

When the token expires, the dashboard shows “⚠ Not synced”. Generate a new one the same way and paste it again. Your statuses are never lost; they stay in the private repo and on each device.

💻 Desktop

  1. App: open the dashboard in Chrome or Edge and click the install icon (⊕ / 🖥) at the right of the address bar.
  2. Notifications: open ntfy.sh/app, click Subscribe to topic, enter the same topic, then click Grant now to allow browser notifications. Keep it installed as an app or a pinned tab.
  3. Sync: ⚙︎ Settings with the same repo and token as on your phone.
